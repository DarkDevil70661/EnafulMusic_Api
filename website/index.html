Getting Started

How it works.

Connect your application to ENAFUL MUSIC API through a simple request-and-response workflow.

01 / ACCESS

Get an API Key

Create an account and obtain your API key when the authentication system is available.

02 / REQUEST

Request Music Data

Send a request to a supported endpoint with your API key.

03 / RESPONSE

Connect Your Bot

Process the API response in your application or supported Telegram Music Bot.

Music API Reference

API endpoints.

Proposed routes for the ENAFUL MUSIC API. These endpoints require a working backend.

GET /api/health

Check whether the API service is running.

GET /api/usage

Retrieve your authenticated API usage.

GET /api/account

View account and subscription information.

POST /api/music/search

Search a configured, supported music catalogue.

POST /api/music/stream

Request an authorized audio stream.

GET /api/plans

View available API subscription plans.

Security

API authentication.

API requests will use a private API key passed through the request header.

Example request header

Keep your API key private. Do not expose secret keys in public frontend JavaScript or repositories.

X-API-Key: YOUR_API_KEY
